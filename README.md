# 组态工作台

Vue 3 + Element Plus + AntV X6 的浏览器组态编辑器。首版 14 个任务已实现：设备、文字、指标、趋势图和自由线条混合编排，条件变色、多图片状态切换、流动动画，以及本机保存、备份和独立发布。

## 本机启动

需要 Node.js 22.12 或以上版本。

```sh
npm ci
npm run dev
```

打开 [本机工作台](http://127.0.0.1:5173)。`npm run build` 构建生产文件，`npm run preview` 在本机查看构建结果。开发和预览服务只监听本机。

## 快速体验

1. 点击顶部“项目 → 载入演示项目”，再点击画布底部“适应内容”：主页面包含水泵状态图片、温度指标与趋势图、直线/折线/曲线和背景，第二页提供返回导航。
2. 在右侧“数据”页签的模拟数据中设置温度 79、80、81、79；只有 81 触发红色。运行状态 0 停止供水流动；恢复为 1 后流量设为负数，供水改为反向。故障状态 1 切换故障图片。
3. 取消某个点位的“可用”勾选，依赖该点位的图元显示异常并回退；恢复后重新按当前样本显示。
4. 点击“保存到本机”，确认“已保存”后刷新。导出项目文件可备份页面、图片和规则；在其他浏览器导入后再保存。
5. 点击“发布到本机”创建独立快照，再点击“项目 → 打开发布版本”。后续草稿修改不改变发布版本，必须重新发布才更新。
6. 运行版点击水泵或指标查看详情；点击“设备详情 →”跳页。名称和数据状态筛选只作用于图元列表，历史范围只作用于当前运行视图。

载入演示、导入项目、新建项目、重开本机之前会保护未保存修改。“新建页面”保留当前项目的其他页面；“新建项目”创建独立内容。

## 编辑方式

工作台采用已确认的原型 A 布局：左侧组件分类与搜索、独立图层区、中间画布、右侧属性面板。顶部三个面板按钮可收起侧栏扩大画布。右侧“属性 / 数据 / 规则 / 页面”分别配置图元外观与状态图片、点位与模拟数据、条件与点击动作、背景；视图操作在画布底部。项目打开、导入导出和演示入口统一放在顶部“项目”菜单。

- 将组件卡片拖入画布任意位置，在释放位置创建图元（以中心落点，支持负坐标），也可点击添加。依次点击路径点绘制直线、折线、曲线；曲线使用起点、两个控制点、终点。按 Esc 取消绘制。线条不吸附设备或网格。
- 拖动和属性面板修改位置、尺寸、旋转、颜色。通过图层列表锁定、隐藏、恢复、调整顺序；选择多个对象后对齐、分布、组合或解组。
- 锁定成员保护整个组合。组合移动保持相对位置；复制组合产生新身份。同一项目内可跨页粘贴，不受背景尺寸限制；切换、新建或导入项目会清空内部剪贴板。
- 支持 Ctrl/Cmd+Z、Y、Shift+Z、C、V、A、S、D，以及 Delete/Backspace 和 Esc。输入框内不会误触画布删除或复制。
- 右键画布图元或图层可复制、粘贴、删除、调整层级、组合、锁定和隐藏；多选时可对齐或等距分布。空白处右键可在该位置粘贴；Escape 关闭菜单。操作遵守锁定保护，并支持撤销。
- 缩放、适应内容、100%、平移和视觉网格在编辑与运行中共用。绘图区域不受宽高限制，可向四周延伸，支持负坐标。按住空格拖动、使用中键或开启平移工具可平移；空白处拖动框选。滚轮以鼠标位置为中心缩放，“适应内容”可找回远处图元。原宽高仅作背景图片参考尺寸，背景颜色覆盖工作区；预览和发布自动适应内容。视图变化不修改文档或撤销历史。
- 显示规则支持六种比较、全部/任一条件、多点位及上下优先级；颜色、图片和流动各使用第一条命中规则。条件解除回到基础配置。

## 数据与限制

使用当前浏览器、当前站点来源的 IndexedDB 保存一个活动项目和一个独立发布快照。更换浏览器、端口、主机名或清除站点数据后不会共享保存；请定期导出备份。导入不自动保存或发布，写入失败保留当前编辑与上次有效版本。

首版提供模拟点位与可替换数据提供方接口，尚未对接真实平台；无设备控制、远程发布、账户或多人协作。支持单层组合和桌面宽屏界面，不包含手机专用编辑体验。

图片支持 PNG/JPEG/WebP，单张不超过 5 MB/2500 万像素；最多 100 张、合计 25 MB，导入项目不超过 50 MB。发布和导入会验证图片、点位、页面目标及文档结构。资源以内嵌内容保存，不依赖上传文件路径。

验证样例为 2 页、11 个图元、4 张图片，不能据此推断大型工程的性能上限。构建仍有打包体积提示，可在后续部署阶段按需拆包。

## 验证

```sh
npm run typecheck
npm test -- --workers=4
npm run build
```

浏览器测试默认使用本机 Microsoft Edge，独立上下文和 5174 端口不读取日常 5173 的保存。可设置 `EDITOR_TEST_PORT` 使用其他端口。其他环境可运行 `npx playwright install chromium` 并设置 `PLAYWRIGHT_CHANNEL=chromium`。
