# 组态编辑器首版实现规格

Status: ready-for-agent

本规格把已确认的组态编辑器需求整理为可实现、可验收的首版范围。工程师使用浏览器制作工业监控、数据大屏与设备拓扑混合页面，业务人员使用本机发布版本查看详情、跳转页面和筛选数据。

日期：2026-10-01。功能范围及测试边界已由用户确认，规格已登记到本地任务跟踪系统，可进入任务拆分阶段。

## Problem Statement

工程师需要在同一张画布中放置设备、图表、指标、文字和自由线条，表达现场设备关系并展示运行数据。页面需要根据实时数据改变颜色、切换设备图片以及调整线条流动方向和速度，不能只是一张静态示意图。

编辑器需要提供完整的基础编辑操作、背景配置和本机保存能力。业务人员应能查看发布后的画面、查看详情、切换页面和筛选数据，同时不影响工程师正在编辑的草稿。

平台负责提供设备点位、实时数值和历史数据。本阶段没有平台接口契约，首版用可控模拟数据验证从编辑到发布的完整链路，并保留替换数据提供方的边界。

## Solution

使用 Vue 3、Element Plus 和 AntV X6 实现浏览器组态编辑器。工程师通过组件库、画布、属性配置及显示规则完成页面制作，保存到本机，并创建独立的本机发布版本。

在同一画布中支持工业监控、大屏展示与设备拓扑内容混合编排。自由线条支持直线、折线和曲线，端点与路径由工程师控制，不吸附设备。显示规则根据点位值触发图元变色、状态图片切换以及线条流动变化。

首版完整演示链路为：绘制设备和管线 → 放置温度图表 → 绑定模拟温度 → 配置超限变色、图片切换及流动规则 → 本机保存 → 本机发布 → 重新打开验证。业务人员在运行页面使用详情、跳转和筛选功能。

## User Stories

### 页面与混合编排

1. 作为工程师，我希望创建和重新打开组态页面，以便持续维护监控画面。
2. 作为工程师，我希望在同一画布放置设备、图表、指标和文字，以便同时表达现场结构与数据。
3. 作为工程师，我希望设置图元名称和展示文字，以便业务人员理解画面内容。
4. 作为工程师，我希望调整图元位置、尺寸和旋转角度，以便还原现场布局。
5. 作为工程师，我希望使用同一本机项目中的多个页面，以便表达不同区域或不同层级的内容。

### 自由绘线与流动

6. 作为工程师，我希望自由绘制直线和折线，以便表示管道、线路和设备关系。
7. 作为工程师，我希望绘制曲线并调整控制点，以便表达弯曲线路。
8. 作为工程师，我希望自由移动线条端点且不吸附设备，以便精确决定线条路径。
9. 作为工程师，我希望设备移动时自由线条保持原位置，以便避免出现隐含连接关系。
10. 作为工程师，我希望设置线条颜色、粗细、实线、虚线和端点箭头，以便区分线路类型。
11. 作为工程师，我希望独立开关流动动画，以便同时表达静态线条样式和动态运行状态。
12. 作为工程师，我希望配置正向、反向、停止及流动速度，以便表达流向和运行状态。
13. 作为工程师，我希望通过点位条件改变流动方向、速度或停止状态，以便画面反映实时数据。

### 背景与基础编辑

14. 作为工程师，我希望设置画布背景颜色，以便配合业务页面的视觉风格。
15. 作为工程师，我希望上传本地背景图并设置适应、铺满、拉伸、平铺及透明度，以便使用现场底图。
16. 作为工程师，我希望背景不参与图元选择，以便操作前景内容时不会误移动背景。
17. 作为工程师，我希望撤销和重做编辑操作，以便修正误操作。
18. 作为工程师，我希望复制、粘贴、重复和删除图元，以便快速创建相似内容。
19. 作为工程师，我希望全选、多选和框选图元，以便批量调整画面。
20. 作为工程师，我希望锁定和解锁图元，以便保护已经完成的布局。
21. 作为工程师，我希望显示或隐藏图元，并能从图层列表找回隐藏图元，以便管理复杂画面。
22. 作为工程师，我希望置顶、置底、上移或下移一层，以便控制遮挡关系。
23. 作为工程师，我希望对齐和等距分布多个图元，以便保持整齐布局。
24. 作为工程师，我希望组合和取消组合，以便一起移动相关图元。
25. 作为工程师，我希望缩放、平移、适应内容和恢复 100% 显示，以便查看全局或编辑细节。
26. 作为工程师，我希望开关网格显示，以便辅助观察位置而不强制吸附线条。
27. 作为工程师，我希望使用常用快捷键，并在输入文字时避免误触画布命令，以便高效编辑。
28. 作为工程师，我希望离开未保存内容前收到提示，以便避免丢失工作。

### 点位与显示规则

29. 作为工程师，我希望从模拟点位列表绑定设备、指标和图表，以便先验证完整数据链路。
30. 作为工程师，我希望实时数值和历史图表有对应的模拟数据，以便验证不同展示类型。
31. 作为工程师，我希望主动调整模拟温度和设备状态，以便复现正常、超限、停止和故障场景。

34. 作为工程师，我希望条件成立时改变图元颜色，恢复正常时还原，以便清楚识别超限。
35. 作为工程师，我希望调整显示规则优先级，以便在多个条件同时满足时得到可预期的结果。
36. 作为业务人员，我希望数据不可用时有明确标识，以便不会把缺失数据误当成正常状态。

### 多图片状态切换

37. 作为工程师，我希望为一个图元配置默认图片和多张状态图片，以便表达同一设备的不同状态。
38. 作为工程师，我希望为每张状态图片配置数据条件，以便自动显示停止、运行或故障图片。
39. 作为工程师，我希望多个状态同时满足时按优先级选择图片，以便优先展示故障等重要状态。
40. 作为工程师，我希望无规则匹配或数据不可用时回到默认图片，以便保留明确的回退表现。
41. 作为工程师，我希望手动预览每张状态图片，以便在绑定数据前检查效果。
42. 作为业务人员，我希望图片切换时设备的位置、尺寸、旋转和层级保持不变，以便画面稳定。

### 保存与发布使用

43. 作为工程师，我希望将页面、规则和图片资源保存到本机，以便刷新或重开后继续编辑。
44. 作为工程师，我希望导出和导入完整项目，以便备份并避免图片依赖原始文件位置。
45. 作为工程师，我希望在预览中检查数据驱动效果且不能误编辑布局，以便验证发布表现。
46. 作为工程师，我希望发布独立版本，以便后续草稿修改不影响已发布画面。
47. 作为业务人员，我希望打开本机发布版本，以便查看工程师确认过的画面。
48. 作为业务人员，我希望点击图元查看详情，以便了解对应点位和当前状态。
49. 作为业务人员，我希望通过配置好的入口跳转页面，以便查看相关区域。
50. 作为业务人员，我希望按配置的条件筛选数据或展示内容，以便关注需要的信息。
51. 作为业务人员，我希望运行页面保留查看操作但不显示编辑控制，以便稳定使用发布内容。

## Implementation Decisions

### 已确认的技术与业务边界

- 技术栈为 Vue 3、Element Plus、AntV X6。用户指定 Vue 3 和 Element UI 后，已接受以 Element Plus 落地的整体方案。
- X6 是图元和自由线条的底层绘图引擎，不以另一套绘图引擎替换；框架界面负责组件库、属性、图层、显示规则与页面管理。
- 工业监控、数据大屏、设备拓扑共享画布。首版不执行工作流，不采集设备数据，不控制设备。
- 真实平台提供点位、实时数值和历史数据；首版使用模拟数据，真实接口地址、鉴权方式和通信协议尚未确定。
- 首版只要求本机保存与本机发布，不包含服务器共享或公网访问。

### 模块责任与数据契约

下列模块划分和数据约束是基于已确认功能提出的实现方案；不代表已有代码或已对接的平台接口。

- 编辑工作区：管理页面、选中对象、工具模式、属性修改、图层与编辑命令。
- 画布适配层：管理 X6 图元、自由线条、选择、变换与视图操作；编辑状态和运行状态共用渲染能力。
- 组态文档：保存格式版本、项目与页面标识、背景、图元、线条、分组、层级、资源引用、点位绑定、显示规则和交互配置。
- 图元保留稳定标识、类别、名称、几何信息、基础样式、可见性与锁定状态；图片图元额外记录默认图片与状态规则，图表记录绑定及展示配置。
- 自由线条保存端点坐标、路径类型、折点或曲线控制点、基础样式及流动配置，不保存设备连接端口关系。
- 资源管理：统一管理背景图、默认图片和状态图片；保存、导出和导入必须包含图片内容，不能只记录临时地址或原始文件路径。
- 数据提供方：对外提供点位目录、实时数据订阅与取消订阅、指定时间范围的历史数据查询。实时样本包含点位标识、值、采样时间和数据质量；历史样本包含时间和值。
- 模拟提供方实现同一数据能力，并允许控制阈值附近的温度、运行状态、故障状态和数据可用性。页面切换时释放旧订阅。
- 规则求值：输入基础显示配置、规则列表和点位样本，输出有效显示状态及数据异常标识，不修改原始组态文档。
- 本机文档存储：负责草稿与发布快照的读取、保存、导入和导出；保存完成后才能显示成功状态。
- 运行页面：只读取预览内容或发布快照，使用相同数据与规则能力渲染，并处理详情、跳转和筛选。

### 自由绘制与编辑交互

- 提供直线、折线、曲线工具；路径完成后允许编辑端点、折点或控制点。切换工具或取消绘制时，不留下半成品图元。
- 线条不吸附设备，移动设备不改变线条。网格仅作为视觉辅助，不改变这一行为。
- 流动正向定义为绘制起点到终点，反向相反。箭头样式与流动方向分别配置；停止流动不会隐藏线条。
- 流动速度采用有明确范围的正数设置；停止状态通过独立选项表达，避免速度为零的歧义。
- 线条基础外观与流动效果分别保存，实线或虚线均可独立开启流动。
- 图元基础变换包含位置、尺寸与旋转；曲线的尺寸与位置变化需要同时变换其端点和控制点。
- 单选、多选、框选和全选保持一致的选中反馈；隐藏图元可从图层列表恢复。
- 锁定图元阻止误移动、变换和删除，仍允许从图层列表解锁；批量操作不绕过锁定。
- 图层顺序和显示状态随页面保存。对齐支持边缘及中心对齐，等距分布至少对三个图元生效。
- 组合保留子图元身份、绑定和规则；组合移动带动成员，取消组合不改变其视觉位置。首版至少支持单层分组，嵌套分组不作为验收要求。
- 连续拖动按一次操作进入撤销历史；样式、规则、背景、分组、层级等文档修改同样可撤销。撤销后执行新编辑应清除失效的重做分支。
- 模拟数据更新、图片状态预览、运行筛选、画布缩放和平移不进入文档撤销历史，也不把文档标记为未保存。
- 复制图元创建新标识，保留其样式、规则和资源引用；粘贴适当偏移位置，避免完全遮住原图元。
- 常用快捷键至少覆盖撤销、重做、复制、粘贴、全选、删除、保存和取消当前操作；文本输入、弹窗输入与画布快捷键隔离。

### 背景

- 背景颜色独立于背景图片。图片支持适应、铺满、拉伸、平铺，图片透明度不影响图元。
- 背景属于页面，在编辑、预览和发布中使用一致的坐标和显示规则，不成为可选图元。
- 更换或移除背景不影响图元位置；背景设置与图片资源随保存和导出保留。
- 建议将页面定义为具有明确宽高的逻辑画布，背景模式相对页面尺寸计算，视口缩放只改变观察比例。

### 显示规则与状态图片

- 规则可包含多个点位条件，支持等于、不等于、大于、大于等于、小于、小于等于；一个条件组选择“全部满足”或“任一满足”。首版不要求任意嵌套表达式。
- 数值比较只接受有效数值，状态比较按点位类型执行，不把空值或不可用样本自动转换为零。
- 规则按可调整的顺序排列。建议颜色、图片、流动三个属性分别选取第一条命中且设置了该属性的规则，使图片与流动能独立响应数据；同一属性不叠加多个冲突结果。
- 每次求值从基础配置开始，条件解除时回到基础颜色、默认图片和基础流动设置，避免残留上一次状态。
- 图片图元配置一张默认图片和任意多张状态图片；切换图片只改变显示资源，不替换图元身份及几何属性。
- 编辑时可手动预览某张状态图片；结束手动预览后恢复规则驱动，手动预览不覆盖已保存的默认图片。
- 无图片条件匹配时显示默认图片；图元依赖的数据不可用时显示默认图片并添加异常标识。其他动态属性建议回到基础样式、停止流动，以免用动画表现为正常运行。
- 多条件中的不可用数据建议采用保守处理：受影响图元展示数据异常并停止动态规则表现，而不将缺失条件当作普通假值后继续展示正常状态。
- 模拟数据提供明确的不可用状态；真实数据过期阈值应由未来平台接入契约指定，不在首版虚构平台时效保证。
- 超限示例使用“温度 > 80”时，80 本身不命中，81 命中，79 恢复默认；故障图片规则可放在运行图片规则之前。

### 保存与本机发布

- 建议用浏览器本地数据库保存结构化文档和图片资源，避免把大量图片写入容量较小的简单键值存储。
- 本机保存指当前浏览器、当前站点来源下的持久保存；清除站点数据、切换浏览器或更换来源后不保证可访问，界面应提供导出备份入口。
- 首版采用显式保存并提示未保存状态；不承诺额外的自动恢复或跨设备同步。
- 导出内容包含格式版本、项目页面、全部引用资源及规则；导入前检查格式、资源引用、标识和页面跳转目标，失败时不破坏当前项目。
- 图片读取失败、资源缺失或存储容量不足必须给出可理解的错误，保留当前未保存编辑，不显示成功提示。
- 本机发布生成独立快照；修改草稿不会改变已发布版本，重新发布才替换当前发布内容。
- 建议发布以本机项目为单位包含全部页面及相关资源，保证项目内页面跳转可用。发布前校验默认图片、资源、点位绑定与跳转目标。
- 预览使用当前草稿，发布页面使用快照；两者均禁止绘制、拖动变形和删除等编辑行为，允许缩放、平移与业务查看操作。

### 业务查看交互

- 图元可配置查看详情或跳转至本项目其他页面；详情至少展示名称、绑定点位、当前值、采样时间和数据状态。
- 筛选不改变组态文档和全局模拟点位。建议首版支持按名称或状态筛选图元列表，以及按时间范围查询历史图表；筛选结果与作用范围应可见。
- 页面切换或关闭时清理数据订阅及动画资源。数据变化本身不触发发布或草稿修改。
- 业务人员不进行设备启停、参数下发、阈值写回或工作流执行。

## Testing Decisions

### 已确认的测试边界

用户已确认以下两处测试边界，后续实现按此编写测试。

1. 浏览器用户操作边界：通过真实界面完成绘图、配置、模拟数据变化、保存、重开和发布，检查用户可见结果。作为主要验收边界，覆盖画布、资源、存储和运行页面的协作。
2. 显示规则输入输出边界：对公开的规则求值能力输入基础配置、条件和点位样本，检查有效图片、颜色、流动状态及异常标识。用于稳定覆盖阈值边界、多条件、优先级、恢复默认及缺失数据。

只测试外部行为，不断言组件内部状态、私有方法、内部调用次数或 X6 的内部实现。图像外观、实际拖动和流动方向由浏览器操作配合视觉检查验证，不仅检查配置值。

当前项目只有领域术语文档，没有现有测试框架、测试用例或可复用的测试边界。新增测试应围绕上述两处边界建立，避免为每个内部模块单独扩大测试范围。

## Out of Scope

- 设备采集、设备控制、参数下发、阈值写回以及自动化执行流程。
- 服务器保存、多人协作、账号权限体系、公网发布和跨设备同步。
- 在没有平台接口契约的情况下实现或声称完成真实平台接入。
- 设备端口吸附、设备移动时自动牵引自由线条、自动拓扑布线。
- 3D 编辑、任意脚本执行、任意嵌套条件表达式及完整编程语言。
- 嵌套分组、高级图表设计器、完整告警管理中心和历史数据存储后端。
- 浏览器数据被清除后的自动恢复、无限制图片存储、跨浏览器共享本地数据库。
- 独立可执行程序或无需启动本地应用即可运行的离线网页导出；首版导出用于项目备份和导入。
