# 07: 条件驱动的颜色变化

Status: ready-for-agent
Blocked by: 06

## What to build

工程师通过可视化条件配置，使图元随模拟数据变色，并在恢复正常或数据异常时得到明确表现。

## 规格依据

父规格：组态编辑器首版实现规格。
用户故事：32–36。
验收场景：A12、A13；A16（规则部分）；扩展 A07、A17。

## Acceptance criteria

- [x] 可添加、修改、删除和排序显示规则，选择点位及等于、不等于、大于、大于等于、小于、小于等于条件。
- [x] 一组条件支持全部满足或任一满足，可引用不同点位；不执行任意脚本。
- [x] 每个显示属性使用第一条匹配且配置该属性的规则；本票交付颜色输出，为图片和流动保留同一规则语义。
- [x] 每次从基础配置求值；条件解除恢复基础颜色，不将上一次命中效果写回基础样式。
- [x] 温度 > 80 的规则在 79、80、81、79 输入序列中只有 81 超限，其余恢复基础颜色。
- [x] 数值条件只比较有效数值，不能将空值、无效样本或不可用状态当成零；依赖数据不可用时显示异常并回退基础表现。
- [x] 保存后重开保留条件、顺序和基础配置；数据变化不把文档标记为未保存；若已有历史机制，规则编辑接入该机制。
- [x] 在已确认的规则输入输出边界测试比较边界、且或、不同点位、优先级、恢复默认和数据异常；浏览器验证配置到显示的链路。

## 测试与交付

只使用已确认的浏览器用户操作边界和显示规则输入输出边界。测试有效显示结果，不断言私有状态或内部调用次数。

## 范围与衔接

采用规格建议的逐属性首个命中和数据异常保守回退语义；后续图片与流动规则复用，不另建冲突的规则系统。
