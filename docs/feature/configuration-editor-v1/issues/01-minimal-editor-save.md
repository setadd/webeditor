# 01: 最小编辑与保存闭环

Status: ready-for-agent
Execution: completed
Blocked by: none

## What to build

工程师可以在浏览器创建组态页面，放置设备占位图元和文字，修改属性与位置，保存到本机并重新打开。以这条可运行链路建立 Vue 3、Element Plus、AntV X6 应用，而不是只交付空项目。

## 规格依据

父规格：组态编辑器首版实现规格。
用户故事：01–04、43（基础部分）。
验收场景：A01、A17（基础部分）。

## Acceptance criteria

- [x] 应用可以按项目说明在本机启动；界面使用 Vue 3 与 Element Plus，画布由 AntV X6 渲染。
- [x] 可以创建有明确逻辑宽高的页面，放置设备占位图元和文字，编辑名称、文字、位置及基础颜色，并即时看到结果。
- [x] 图元具有稳定且唯一的标识；选择与属性编辑始终作用于正确图元。
- [x] 显式本机保存后刷新和重新打开，页面、图元标识、文字、位置及颜色保持一致。
- [x] 文档记录格式版本；页面、图元和基础样式作为可扩展的文档保存，后续规则或图片能力不要求替换已有项目。
- [x] 保存成功只在持久化完成后提示；失败时保留未保存内容并提示原因。
- [x] 提供可复现的浏览器验收：创建页面、放置图元、编辑、保存、刷新、核对结果。

## 测试与交付

通过浏览器用户操作边界验证编辑和持久保存，使用独立的空白测试存储；不通过断言 X6 内部状态代替可见结果。

## 范围与衔接

本票先交付单页面和基础图元，不实现设备控制、真实平台接入、状态图片或发布。当前项目没有业务代码，无前置重构任务。
