# 14: 完整场景验收与交互补齐

Status: ready-for-agent
Blocked by: 08, 09, 10, 12, 13

## What to build

工程师能够完成从绘图、绑定、规则、保存到发布的完整示例；补齐画布视图操作并验证所有功能组合后仍然正确。

## 规格依据

父规格：组态编辑器首版实现规格。
用户故事：01–51（整体验收），25–26（本票交付）。
验收场景：A01–A24（全量），A11（本票交付）。

## Acceptance criteria

- [ ] 交付缩放、平移、适应内容、恢复 100% 和网格显示开关；改变视图不改变文档坐标或未保存状态，不启用线条吸附。
- [ ] 完成设备、文字、指标、温度图表、三种线条与背景共存的可复现演示页面。
- [ ] 温度阈值变色、运行故障状态切图、线条正反流动和停止共同工作；异常数据与恢复表现一致。
- [ ] 覆盖规格 A01–A24，每项记录操作、预期、实际结果和测试或视觉验证证据，修复发现的集成缺陷。
- [ ] 验证带状态图片及规则的图元复制、分组、锁定、隐藏、层级调整与撤销重做互不破坏身份和绑定。
- [ ] 验证完整项目保存、刷新、导出、空白存储导入、发布及重新发布，资源齐全且草稿和快照隔离。
- [ ] 运行页面实际查看详情、跳转和筛选，编辑控制不可用；视图和数据变化不产生撤销记录。
- [ ] 后台视图、切换页面和关闭详情不残留旧订阅或动画；记录代表性页面规模及运行环境，不声称未验证的性能上限。
- [ ] 提供本机启动与使用说明、可复现验收步骤和已知限制，说明浏览器本地保存范围及导出备份用途。

## 测试与交付

以浏览器全流程和规则输入输出回归为准；实际图片与流动效果需视觉检查。各前置任务的测试在各自交付时完成，本票不代替它们。

## 范围与衔接

不扩展到真实平台接入、远程发布或设备控制。仅当前置任务全部完成且全量验收通过，才能声明首版实现完成。

ready-for-agent 表示任务描述已准备好；只有 Blocked by 中所有前置任务实际完成后，才可开始实现。
