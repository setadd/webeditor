# 03: 自由直线、折线与曲线

Status: ready-for-agent
Execution: completed
Blocked by: 02

## What to build

工程师可以自由绘制直线、折线与曲线，编辑路径和样式，在设备附近精确布局并保存。

## 规格依据

父规格：组态编辑器首版实现规格。
用户故事：06–10。
验收场景：A02、A03；扩展 A07、A17。

## Acceptance criteria

- [x] 可选择直线、折线、曲线工具，在画布确定路径并完成绘制；取消或切换工具不遗留半成品。
- [x] 完成后可调整起终点、折点和曲线控制点；曲线有可见且可操作的控制柄。
- [x] 所有线条端点为自由坐标，不吸附设备、端口或网格；移动设备不会牵引线条。
- [x] 线条支持颜色、粗细、实线、虚线及起终点箭头，属性修改实时可见。
- [x] 线条可选择、复制、删除和整体移动；尺寸及旋转变化同步转换路径点，保持正确形状。
- [x] 绘制和路径编辑纳入撤销重做，连续拖动控制点只需一次撤销。
- [x] 本机保存和重开后路径类型、全部路径点、几何信息和样式完整恢复。
- [x] 浏览器实际操作验证三种路径、控制点拖动、不吸附及设备移动后线条保持原位置。

## 测试与交付

沿用浏览器边界，检查实际路径和交互；不用仅验证序列化坐标代替绘制验证。

## 范围与衔接
