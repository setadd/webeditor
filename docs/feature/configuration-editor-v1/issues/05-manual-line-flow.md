# 05: 手动配置线条流动

Status: ready-for-agent
Execution: completed
Blocked by: 03

## What to build

工程师可以为三种自由线条分别配置流动开关、正反方向、停止和速度，并观察与保存实际效果。

## 规格依据

父规格：组态编辑器首版实现规格。
用户故事：11–12。
验收场景：A04；扩展 A07、A17。

## Acceptance criteria

- [x] 直线、折线与曲线均能开启流动；实线和虚线基础样式均支持动画。
- [x] 正向为绘制起点到终点，反向相反；箭头样式独立于动画方向。
- [x] 支持明确的停止状态和有范围的正数速度配置，停止后基础线条仍然可见。
- [x] 流动外观与基础颜色、线宽及虚线配置分别保留，不用开启动画覆盖原样式。
- [x] 调整方向和速度后实际动画立即改变，不需要重建线条或刷新页面。
- [x] 手动配置纳入撤销重做和本机保存，重新打开恢复配置。
- [x] 动画每帧更新不进入撤销历史，也不标记文档为未保存；移除线条或退出页面清理动画。
- [x] 浏览器验证实际方向、速度变化、停止和恢复，并记录视觉验收结果。

## 测试与交付

通过浏览器交互与视觉检查验证流动，不能仅凭属性面板值判断方向正确。
