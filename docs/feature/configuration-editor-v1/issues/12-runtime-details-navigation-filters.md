# 12: 业务查看、跳转与筛选

Status: ready-for-agent
Blocked by: 06, 11

## What to build

工程师配置图元查看动作，业务人员在预览与发布页面查看点位详情、跳转项目内页面并筛选数据。

## 规格依据

父规格：组态编辑器首版实现规格。
用户故事：48–51。
验收场景：A22；扩展 A21。

## Acceptance criteria

- [x] 图元可配置查看详情或跳转本项目目标页面，配置可保存并随发布快照使用。
- [x] 详情展示图元名称、绑定点位、当前值、采样时间及数据状态，数据变化时正确更新。
- [x] 页面跳转目标可选且有有效性校验，目标缺失时给出可理解提示。
- [x] 支持按名称或状态筛选图元列表，以及按时间范围查询历史图表；筛选作用范围及清除入口明确。
- [x] 筛选不修改组态草稿、发布快照或全局模拟点位，不触发未保存标记。
- [x] 预览与发布均可使用详情、跳转和筛选，同时仍禁止编辑图元。
- [x] 连续跳转和关闭视图释放旧订阅及动画；重复打开详情不累积旧数据更新。
- [x] 浏览器验证多页面导航、实时详情、不同筛选结果、清除筛选及只读保护。

## 测试与交付

通过浏览器验收业务操作和结果，用可控模拟样本使预期明确，避免依赖真实平台。
