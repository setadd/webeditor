# 08: 一个图元的多图片状态切换

Status: ready-for-agent
Execution: completed
Blocked by: 04, 07

## What to build

工程师为同一设备图元配置默认图片与多张状态图片，用点位条件自动切换并手动预览。

## 规格依据

父规格：组态编辑器首版实现规格。
用户故事：37–42。
验收场景：A14、A15、A16；扩展 A07、A17。

## Acceptance criteria

- [x] 一个图元可上传并保存默认图片和多张状态图片，复用已有本地资源能力，至少支持 PNG、JPEG、WebP。
- [x] 状态图片通过已有条件组与优先级选择，运行和故障同时成立时以排序在前的匹配图片为准。
- [x] 没有匹配规则时显示默认图片；依赖数据不可用时显示默认图片与异常标识，恢复数据后重新求值。
- [x] 图片切换保持图元标识、位置、尺寸、旋转、层级、绑定及交互配置不变。
- [x] 手动预览可以逐张切换并退出；退出后恢复规则驱动，不覆盖默认图片或已保存配置。
- [x] 增删图片和规则等编辑支持撤销重做；运行切图及手动预览不污染文档历史。
- [x] 保存刷新后默认和状态图片、条件、顺序完整恢复；复制设备时保留状态配置并生成新图元身份。
- [x] 测试正常、运行、故障同时成立、无匹配、数据异常、恢复与手动预览退出，验证图片确实显示而非只有资源引用。

## 测试与交付

规则输出边界验证资源选择与回退；浏览器上传和显示验证几何不变、图片持久化与预览行为。

## 范围与衔接

不通过创建或删除设备图元实现状态切换。

ready-for-agent 表示任务描述已准备好；只有 Blocked by 中所有前置任务实际完成后，才可开始实现。
