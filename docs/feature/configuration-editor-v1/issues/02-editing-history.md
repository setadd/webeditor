# 02: 基础编辑与撤销重做

Status: ready-for-agent
Blocked by: 01

## What to build

工程师可以选择并批量编辑图元，复制粘贴、删除、变换、撤销重做，并通过快捷键和未保存提示保护工作。

## 规格依据

父规格：组态编辑器首版实现规格。
用户故事：04、17–19、27–28。
验收场景：A07、A08、A23（基础部分）。

## Acceptance criteria

- [ ] 支持单选、追加多选、框选、全选，选中反馈明确；点击空白区域可取消选择。
- [ ] 支持移动、尺寸调整和旋转，连续拖动按一次操作记录；保存重开保留结果。
- [ ] 复制、粘贴和重复产生新图元标识，粘贴有可见偏移，保留原有配置；批量删除只作用于选中对象。
- [ ] 新增、删除、属性修改、变换及批量操作可撤销重做；撤销后新编辑清除旧重做分支。
- [ ] 历史机制能够供后续线条、背景、规则和分组编辑复用；保存的文档与当前显示一致。
- [ ] 常用快捷键覆盖撤销、重做、复制、粘贴、全选、删除、保存和取消；输入框、文本编辑与弹窗内操作不会误触画布。
- [ ] 文档实际修改才标记未保存；保存清除标记；离开或替换有未保存内容的页面时允许取消，取消后内容保留。
- [ ] 浏览器验收覆盖批量编辑、单次拖动撤销、撤销分支失效、复制独立身份及输入焦点隔离。

## 测试与交付

通过浏览器验证操作顺序与可见内容；后续新增能力各自在其任务中接入已有历史机制。
