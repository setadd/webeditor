# 04: 背景与本地图片资源

Status: ready-for-agent
Blocked by: 02

## What to build

工程师可以设置画布背景色、上传背景图并调整铺放方式，保存后重新打开仍保留图片。

## 规格依据

父规格：组态编辑器首版实现规格。
用户故事：14–16、43（图片资源部分）。
验收场景：A06；扩展 A07、A17、A19。

## Acceptance criteria

- [ ] 背景颜色可配置，图片可上传、更换和移除；至少支持静态 PNG、JPEG、WebP。
- [ ] 提供适应、铺满、拉伸、平铺四种显示模式和图片透明度，模式相对逻辑页面尺寸计算。
- [ ] 背景处于图元之下且不可选中，改变背景不会移动图元或改变前景透明度。
- [ ] 背景修改可撤销重做，撤销恢复原图片、颜色、模式及透明度。
- [ ] 持久化图片内容并用稳定资源引用关联文档，不依赖上传源文件路径或临时浏览器地址。
- [ ] 刷新和重新打开恢复背景；移除源文件后已保存图片仍可用。
- [ ] 读取失败、文件格式不支持和持久化失败时提示原因并保留原有效背景。
- [ ] 资源保存能力可供后续状态图片复用；文档保留备份所需的资源内容。

## 测试与交付

浏览器上传本地测试图片，验证四种模式、透明度、不可选中、历史恢复和刷新持久化。
