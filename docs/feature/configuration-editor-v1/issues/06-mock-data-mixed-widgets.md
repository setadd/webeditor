# 06: 模拟点位与混合数据展示

Status: ready-for-agent
Blocked by: 01
Execution: completed

## What to build

工程师可以在同一页面放置设备、指标与温度趋势图，选择模拟点位并观察实时和历史数据。

## 规格依据

父规格：组态编辑器首版实现规格。
用户故事：02、29–31、36（数据质量展示部分）。
验收场景：A01；A16、A17（点位与图表部分）。

## Acceptance criteria

- [x] 组件库支持设备、指标和趋势图，与已有文字图元共存；选择组件后可配置点位绑定。
- [x] 提供温度数值、运行状态、故障状态等模拟点位，界面可手动控制数值与可用性。
- [x] 点位目录、实时订阅与取消订阅、按时间范围查询历史数据有统一数据提供方边界，不绑定真实平台地址或鉴权方案。
- [x] 实时样本含点位标识、值、采样时间及质量；历史样本含时间和值，图表显示匹配的数据。
- [x] 设备和指标显示所绑定点位的当前值，图表显示实际模拟历史序列；不可用或缺失值明确标识，不能显示为零。
- [x] 绑定与展示配置随文档保存，刷新后可以恢复绑定并继续接收当前模拟数据。
- [x] 模拟数值变化不修改草稿、不进入撤销历史；解绑、切换页面和销毁视图时释放旧订阅。
- [x] 在已有编辑能力的环境中，新增组件可沿用选择、属性编辑和保存能力；测试验证混合画布可见结果。

## 测试与交付

通过浏览器选择绑定、调节模拟数据并检查实时值及趋势图。平台边界通过用户行为验收，不新增未约定的内部模块测试边界。
