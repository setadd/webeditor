# 10: 图层、对齐与组合编辑

Status: ready-for-agent
Blocked by: 02, 03

## What to build

工程师通过图层管理、对齐分布与组合操作管理复杂页面，设备及自由线条都保持正确布局。

## 规格依据

父规格：组态编辑器首版实现规格。
用户故事：20–24。
验收场景：A09、A10；扩展 A07、A08、A17。

## Acceptance criteria

- [x] 图层列表展示图元并能选择、显示隐藏、锁定解锁，隐藏对象始终可找回。
- [x] 锁定阻止误移动、变换和删除；多选、全选或组合操作不能绕过成员锁定。
- [x] 支持置顶、置底、上移和下移一层，显示遮挡关系正确且可保存。
- [x] 多个对象可边缘或中心对齐；三个及以上对象可等距分布。
- [x] 支持单层组合和取消组合；组合移动带动成员，取消后保留位置、身份、资源、绑定和规则。
- [x] 自由线条参与组合时端点与全部控制点正确变换，不产生设备吸附或隐式连接。
- [x] 图层、对齐、分组与批量操作有一致撤销粒度；保存刷新后成员关系和可见性、锁定与层级一致。
- [x] 通过浏览器验证隐藏后恢复、锁定保护、不同形状混合对齐、组合与取消组合；后续新增图元类别沿用通用行为。

## 测试与交付

浏览器边界验证实际位置、遮挡和成员行为，不以内部组合数据结构作为唯一断言。
