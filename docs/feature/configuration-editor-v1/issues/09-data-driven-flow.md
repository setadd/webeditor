# 09: 数据驱动的流动动画

Status: ready-for-agent
Blocked by: 05, 07

## What to build

工程师配置点位条件，让已有自由线条自动改变流向、速度或停止状态，条件解除后恢复基础流动配置。

## 规格依据

父规格：组态编辑器首版实现规格。
用户故事：13、33–36（流动规则部分）。
验收场景：A05、A13、A16；扩展 A07、A17。

## Acceptance criteria

- [ ] 显示规则可配置流动方向、速度与停止状态，复用现有条件编辑和优先级语义。
- [ ] 演示运行状态使线路流动、停止状态停止、负流量反向；明确绘制起终点作为方向参照。
- [ ] 同一线条的颜色和流动按各自属性取首个命中规则，互不覆盖无关属性。
- [ ] 条件解除恢复手动基础配置；数据不可用时停止动态流动并显示异常，恢复后使用当前数据重新求值。
- [ ] 规则效果不改写手动基础配置；数值变化不进入历史或产生未保存标记。
- [ ] 规则编辑可撤销重做，保存重开保留配置，直线、折线和曲线都按规则运行。
- [ ] 切换、删除线条和卸载视图后不会残留动画或旧订阅。
- [ ] 规则输出测试与浏览器视觉检查共同覆盖方向、速度、停止、优先级以及异常恢复。

## 测试与交付

规则边界验证有效流动配置，浏览器检查实际沿路径流动方向和变化；不能只测试面板文字。

## 范围与衔接

本票不依赖状态图片；两种规则输出可在各自前置完成后独立开发。
