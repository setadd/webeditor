# 13: 完整项目导入导出与失败保护

Status: ready-for-agent
Blocked by: 04, 11

## What to build

工程师可以导出带全部图片资源的完整多页面项目，在空白本地存储中导入，并在失败时保留现有工作。

## 规格依据

父规格：组态编辑器首版实现规格。
用户故事：43–44。
验收场景：A18、A19；扩展 A17。

## Acceptance criteria

- [ ] 导出包含格式版本、多页面、当前所有图元配置、背景和全部引用图片资源，不依赖原始文件或临时地址。
- [ ] 在空白存储中导入可继续编辑和本机保存，图元标识、路径、样式与已存在的业务配置保持一致。
- [ ] 导入前校验文档结构、支持的版本、标识唯一性、资源引用和页面跳转目标。
- [ ] 非法内容、缺失资源、不支持版本或读取失败时提示原因，不部分覆盖当前有效项目。
- [ ] 替换存在未保存内容的项目需提供保护；用户取消后原内容和未保存状态保持不变。
- [ ] 容量不足或写入失败不显示保存成功，不破坏已保存草稿和发布快照，当前待保存内容可继续导出备份。
- [ ] 图片在原上传文件移动或删除后仍可通过导出导入恢复。
- [ ] 导入默认恢复可编辑项目，不自动替换已有发布快照；重新发布由明确操作完成。
- [ ] 本票可用背景图与多页面验收；状态图片及显示规则完成后的完整往返恢复在 14 中验证，不要求其作为开发前置。

## 测试与交付

浏览器执行导出、隔离存储导入与编辑；覆盖损坏文件、缺资源、版本不支持及存储失败后的用户可见保护。

## 范围与衔接

导出用于项目备份和恢复，不承诺无需启动本地应用的可运行网页包。

ready-for-agent 表示任务描述已准备好；只有 Blocked by 中所有前置任务实际完成后，才可开始实现。
