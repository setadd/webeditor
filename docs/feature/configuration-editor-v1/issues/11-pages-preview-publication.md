# 11: 多页面、预览与本机发布

Status: ready-for-agent
Blocked by: 01

## What to build

工程师可以管理多个页面，预览当前草稿并发布项目快照，业务人员在同一浏览器打开独立运行版本。

## 规格依据

父规格：组态编辑器首版实现规格。
用户故事：05、45–47、51。
验收场景：A20、A21；扩展 A17、A23。

## Acceptance criteria

- [ ] 项目支持创建、命名和切换多个页面，页面标识稳定；保存和重开恢复页面内容及当前项目。
- [ ] 预览读取当前草稿，发布读取独立快照；预览退出不意外修改草稿。
- [ ] 发布以项目为单位包含所有页面和当前引用资源，成功前完成文档引用校验与持久化。
- [ ] 发布后修改和保存草稿，运行版本保持旧内容；重新发布后才更新，刷新仍能打开发布快照。
- [ ] 预览与发布禁止绘制、选择变换、删除和编辑快捷键；预留业务交互，已有缩放和平移不受影响。
- [ ] 发布失败保留前一次有效快照及草稿，显示错误而非发布成功。
- [ ] 未保存草稿离开时提供明确保护；发布快照独立保存，发布行为本身不伪装成草稿保存成功。
- [ ] 在仅具备 01 的基础页面上可完整演示；后续图元类型及规则沿用统一文档与运行渲染能力，不依赖其先实现。

## 测试与交付

通过浏览器编辑内容 A、发布、修改为 B、重开运行仍为 A、重新发布才变为 B；验证编辑入口和快捷键被禁用。

## 范围与衔接

本机发布限定同一浏览器与站点来源；无服务器共享、账户系统或独立可执行程序。

ready-for-agent 表示任务描述已准备好；只有 Blocked by 中所有前置任务实际完成后，才可开始实现。
