# 04：编辑器右键菜单

Status: ready-for-agent
Blocked by: 03
Execution: completed

## 用户请求

将适合右键菜单的功能放到右键菜单，包括复制、粘贴、删除、置顶、置底。

## 实现与验收范围

- 画布图元及图层列表支持右键菜单。右键未选图元切换目标，右键已选图元保留多选和组合。
- 提供复制、粘贴、重复、删除、置顶、置底、上移/下移一层、组合/取消组合、锁定/解锁、隐藏/显示；多选时提供对齐和等距分布。
- 空白处右键清除选择，提供粘贴、全选、撤销、重做；无选择或无剪贴板时相关命令禁用。
- 画布右键粘贴以菜单打开位置为所复制内容的包围框中心，支持缩放和平移；图层菜单和原快捷键粘贴沿用偏移 24 px 的方式。复制保留相对布局。
- 锁定成员保护组合；受保护选择的删除、顺序、组合、对齐及隐藏命令禁用；复制和解锁可用。
- 菜单贴近右键位置并限制在窗口内，过长可滚动；支持方向键、Home/End、Enter、Escape，点击外部、切换页面或运行模式时关闭。
- 绘制过程中不打开编辑菜单；预览/发布不提供编辑菜单。右键打开与关闭不改保存状态，修改沿用原撤销历史和保存行为。
- 现有快捷键及顶部工具栏入口保留；按用户后续批注移除图层面板底部的层级、组合、对齐、分布按钮，这些操作通过右键菜单使用。本次不改变数据绑定、规则或发布机制。

## 验证边界

沿用已确认的浏览器操作验收。`tests/context-menu.spec.ts` 验证选择目标、多选、层级、锁定保护、显示隐藏、粘贴落点、删除撤销、窗口边缘、关闭及运行模式隔离。先验证菜单缺失时测试失败，再实现通过。
