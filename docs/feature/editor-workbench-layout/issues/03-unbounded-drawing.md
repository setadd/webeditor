## 用户请求与实现范围

用户澄清“无限工作区是指不限制绘图区域范围”，并要求“编辑器不限制绘图区域”。本任务取代 02 中图元受页面尺寸约束的解释。

## 验收标准

- 设备、图表、指标、文字和自由线条可以放在任意方向，支持负坐标及超出背景参考宽高的坐标；组件拖入、移动、属性修改和缩放图元不受原页面边界限制。
- 直线、折线、曲线和路径控制点可在原区域外编辑；保持自由绘制、不吸附。
- 远处仍可框选、组合移动、复制粘贴、撤销重做；复制保留相对位置。
- 保存重开、备份导入及发布保留这些坐标；预览和发布打开时适应全部可见图元，支持原有点击动作。
- 背景颜色覆盖工作区；背景图片保持以原点为基准，原宽高作为背景参考尺寸。界面不再暗示其为绘图边界。
- 空格加拖动、中键及平移工具用于移动视口；空白处左键拖动用于框选。视图操作不改文档或撤销历史；“适应内容”可找回远处和大跨度内容。

## 实现与验证

移除编辑和文档读取中的页面边界限制，保留有限数值、正尺寸及最小编辑尺寸校验。绘图表面跟随当前可见世界区域调整，图元仍保存世界坐标；背景尺寸和文档结构保持兼容。

浏览器验收覆盖负坐标、超尺寸图元、远处曲线控制点、框选组合和复制、保存重开及发布点击；沿用已有背景、导入导出、自由绘线及编辑回归。新用例位于 `tests/unbounded-canvas.spec.ts`。
