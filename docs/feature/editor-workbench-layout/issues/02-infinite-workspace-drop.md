## 用户请求与实现范围

用户要求“我要无限画布的效果，左侧组件要支持拖入画布”，逐点迭代本次两项能力。

本次将“无限画布效果”解释为无限工作区，保留现有组态页面尺寸和发布范围。已向用户列出另一种选择（图元也能放到原页面外），未收到改为该范围的指示时按前者实现。

## 验收标准

- 工作区可任意方向持续平移，不再受滚动容器边界限制；页面内仍可框选和绘图。
- 支持中键、空格加拖动、平移工具，以及页面外围空白直接拖动；文本输入不被空格快捷键拦截。
- 滚轮以鼠标位置为中心缩放，缩放范围 10%–400%；适应内容可找回图元。
- 左侧设备、趋势图、指标、文字卡片可拖入页面，图元中心对应落点；缩放和平移后位置仍准确。
- 图元在页面边缘自动限制到可容纳的位置；页面外释放、禁用状态及运行模式不接受新增。
- 拖入一次对应一个撤销步骤，支持重做、保存、重新打开；原有点击添加保留。
- 平移和缩放不会修改图元坐标、保存状态或文档撤销历史。

## 验证边界

沿用已确认的浏览器操作验收。`tests/canvas-workspace.spec.ts` 覆盖拖入、落点、撤销恢复、持久化、双向平移、鼠标锚点缩放、四种组件和取消拖入。旧平移用例改为检查画面实际移动，不再依赖已移除的滚动容器实现。
