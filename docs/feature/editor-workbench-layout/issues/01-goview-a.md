## 依据

## 交付范围

- 顶部紧凑项目栏，保留常用保存、预览、发布入口，项目创建、打开、导入导出和演示入口归入项目菜单。

- 中间画布，上方绘图与编辑工具、下方缩放与平移工具；三个侧栏可以独立收起。
- 右侧属性、数据、规则、页面四个页签，分别配置图元、点位、显示条件与交互、页面背景。
- 深色工作台与统一的预览、弹窗配色；文档定义、存储格式、规则执行和发布语义保持兼容。
